# 核战 · 10 分钟 MVP

单文件浏览器游戏，无依赖、无构建。

## 运行

直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 操作

1. 选国家数（2 / 4 / 8）和配装预设 → 开始
2. 底部选武器 → 点击地图上的敌方目标
3. 左上角 `×1 ×2 ×4 ×8` 是**倍速**，试玩建议先 ×2

## 这一版实现了什么

| 设计项 | 状态 |
|---|---|
| 10 分钟单局（600 秒）+ 四阶段（部署/危机/交换/清算） | ✅ |
| 3 种武器：战术弹 / 战略弹 / 拦截弹，5/2/3 点造价 | ✅ |
| 150 点预算与三种预设（均衡/打击/堡垒） | ✅ |
| 升级阶梯：0→1→2→3→4，逐级 + 45 秒冷却 | ✅ |
| 毁伤公式 R=4600·(Y/1000)^⅓·(5/H)^⅓，P=1−e^(−0.5(R/CEP)²) | ✅ |
| 战术弹 600km 射程 / 战略弹 90 秒飞行 / 拦截 Pk 0.6 | ✅ |
| 军事基地被毁 = 损失 30% 剩余战略弹（逼你「用或丢」） | ✅ |
| 7 个 AI 国家，遵守同一套升级闸门 | ✅ |
| 结算画面 | ✅ |

## 这一版**没有**做（故意的）

- 预授权/死手系统（8 秒决策窗口的压力还没进来）
- 联盟、外交、民防疏散
- 拦截弹的手动分配（目前全自动）
- 音效、动画打磨

## 试玩时重点看这四件事

1. **前 60 秒有没有事做**（T-PACE）——如果没有，说明部署期太空
2. **升级闸门是不是太快或太慢**——现在是 45 秒/级，第一次打城市最早在 3 分钟
3. **10 分钟结束时是意犹未尽还是早就够了**（T-END）
4. **战术弹到底有没有用**——600km 射程在 8 国图上只够得着邻国

参数全在 `index.html` 顶部的 `CFG` 里，改完刷新即可。

设计文档见 `docs/design/parameters.md`。
